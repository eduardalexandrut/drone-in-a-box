# Welcome to DIB Documentation.

A prototype distributed **Edge-to-Cloud** system for automating industrial technical inspections (**RaaS - Robot as a Service**).

This project simulates a ground infrastructure (_Hangar_) and a flight unit (_Drone_) communicating in real time through a 
central _MQTT broker_, ensuring a secure, fault-tolerant architecture based on _Finite State Machines (FSM)_.
